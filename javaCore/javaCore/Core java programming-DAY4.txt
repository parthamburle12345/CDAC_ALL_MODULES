What is object-Oriented Programming

Object-Oriented Programming(oop) is a programming approach
where a program is designed using classes and objects.

Object
-object is a real world entity(things)
-object has two things (data:properties)(behaviour:method)
-object is an instance of a class
-object takes memory

class:
 - class is a template /blueprint
 - the class is defining the properties and the behaviour of the object
 - is used to create object
 - it doesn't take memory
