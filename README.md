## 🚀 How to Use

```bash
# Clone the repository
git clone https://github.com/parthamburle12345/CDAC_ALL_MODULES.git

# Navigate to the repo
cd CDAC_ALL_MODULES

# For Python / Data Analytics / ML notebooks
# Create a virtual environment
python -m venv .venv
.venv\Scripts\activate       # Windows
pip install numpy pandas matplotlib seaborn scikit-learn jupyter

# Launch Jupyter
jupyter notebook

# For Java projects
# Import into Eclipse or IntelliJ IDEA
```
