## 🛠️ Modules Breakdown

### 1. Data Analytics
- Data manipulation, analytical techniques, and function mixins.
- Hands-on exercises covering NumPy, Pandas, data exploration, and preprocessing workflows.

### 2. Core Java (`javaCore`)
- **Fundamentals & OOP**: Classes, Objects, Inheritance, Polymorphism, Abstraction, and Interfaces.
- **Collections Framework**: Hands-on usage of `ArrayList`, `LinkedList`, `HashMap`, `Queue`, and `Stack`.
- **Exception Handling**: Built-in exception handling and custom exception hierarchies.
- **Advanced Core Topics**: Multithreading, File I/O (Character/Object streams), and Database Connectivity via **JDBC** (Statements & PreparedStatements).

### 3. Mathematics and Statistics for AI
- Linear Algebra (Vectors, Matrices, Eigenvalues, Transformations).
- Calculus & Optimization techniques powering modern Machine Learning algorithms.
- Probability theory, statistical inferences, hypothesis testing, and continuous/discrete distributions.

### 4. CDAC Project
- Project roadmap, schedules, milestones, and documentation for the postgraduate diploma batch capstone project.

### 5. Python Programming
- Python language fundamentals, syntax, control flows, and data structures.
- Advanced features: Decorators, Generators, Comprehensions, Lambda functions, and Context Managers.
- Real-world mini projects & assessments:
  - Library Book Management System
  - Student Grade Management System
  - Product Inventory Management System
- Web development fundamentals using **Flask** and REST API design.
